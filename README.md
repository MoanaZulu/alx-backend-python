# Python Generators Project

This project explores advanced use of Python generators to handle large datasets efficiently, simulate real-time data updates, and optimize performance in data-driven applications. By leveraging the `yield` keyword, we implement memory-conscious solutions that integrate seamlessly with SQL databases and support streaming, batching, and aggregation.

### Task 1: Stream Users from SQL Database

Implemented a generator function `stream_users()` that connects to the `ALX_prodev` MySQL database and yields rows from the `user_data` table one by one. This approach ensures memory-efficient access to user records, especially useful when working with large datasets.
